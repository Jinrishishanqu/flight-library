逐个详情

pixiv 小说 · 主力源

整条管线最开始的数据来源。走站内 AJAX 接口，不用浏览器。

  • 搜索：GET /ajax/search/novels/{关键词}?word=…&order=date_d&mode=all&p=1&lang=zh
  • 取正文：GET /ajax/novel/{id}?lang=zh，正文在 body.content，标签 tags.tags[].tag
  • 需要登录 Cookie（PHPSESSID），不带 Cookie 也能读部分公开作品
关键词策略是决定命中率的关键：直接搜「同人」命中率只有 21%（斗破苍穹 tag 下 60 篇仅 13 篇是 H）； 改成「角色名 / 作品名 + H 词」后命中率到 80–90%。H 词共 66 个，含 调教/中出/淫/凌辱/催眠/肉/奴/媚药 等。

第一版主移动版 · 最省事

免登录、无需代理，直接用 POST 搜、GET 爬。这是「不下载压缩包、直接爬正文」路线的首选。

# 搜索（必须 POST，字段 wd）
curl -s -X POST "https://m.diyibanzhu.space/wap.php?action=search" \
     --data-urlencode "wd=斗破苍穹" --data "objectType=2"

# 目录页：/list/<id>.html      例 1116 = 《斗破苍穹之萧薰儿的征程》14 章
# 章节页：/view/<id>.html      正文在 <div id="nr1">，<br /> 换行

正文头部固定夹「作者 / 字数 / 日期 / 章节名」，另有一段 #announceinfo 广告要剔掉。

实测样例：目录 /list/1116.html《斗破苍穹之萧薰儿的征程》14 章；章节 /view/735002.html。搜索页 /wap.php?action=search。

关键词命中书目数：斗破 20、斗罗 15、凡人修仙传 5、大主宰 4、武动乾坤 3、完美世界 3、遮天 2、神印王座 0、元尊 0。 按每本平均 30 章算，这里还有几百章没抓。

同一站另有 lessj.com（200/27KB 可用）、ttshu5.com（503）、beifuzhi.com（只返回 278 字节空壳）。

老王论坛 laowang.vip · 花币

Discuz 论坛，资源以附件（zip/rar）形式发布，解压密码通常写在帖内。实测买过一份《斗破苍穹同人大合集 93 个文件》，2.44 MB / 4 软妹币，解压得 100 个 txt。

  • 登录：POST /member.php?mod=logging&action=login&loginsubmit=yes&loginhash=XXXX，字段 formhash / referer / username / password / cookietime
  • 登录被 clicaptcha 拼图滑块拦住，先过验证再带隐藏域 clicaptcha-submit-info 提交
  • 验证图：GET /captcha/tncode.php?t=<random> → WebP 240×450（上=背景含缺口，中=滑块，下=参考图）
  • 校验接口：POST /captcha/check.php，body 形如 tn_r={offset}&track={b64}&ts={ms}&sign={fnv}
  • 软妹币靠每日签到攒，积分不等于软妹币——这点踩过坑
track 是 trackInfo JSON 与固定密钥 GWDiugh398huiw0ioOYGd0934hew 逐字符 XOR 后 base64； sign 是 FNV-1a 变体。理论上可以纯脚本伪造，但更省事的是浏览器手动拖一次。

已确认可搜到的门槛帖：thread-1710528（斗破 93 文件，已买到）、thread-645950（斗破最全）、thread-1483589（斗罗 139 本）、thread-511261（绝世淫门斗罗）、thread-424725（土豆同人合集）。

萌の领域 moezone.app · 要登录

WordPress + inn 主题。帖子列表、标题、悬赏金额都能匿名看，正文被隐藏内容插件挡住，只显示「登录查看」。

  • 帖子页：/forum/<id>.html，如 904451 是「求几个刘备文网站链接」（悬赏 500 萌币）
  • 资源帖带度盘链接，实测 /113385.html（斗破+斗罗 H 文大全 2.34MB）匿名只返回「登录查看」
  • 正文容器：.inn-singular__post__body__content；评论走 admin-ajax.php，评论内容在 #moe-comment-preload 的 JSON 里
结论：注册账号后可用；抓取时要先剥 <style>/<script> 再定位正文容器，否则会被主题 CSS 淹没。

懒盘搜索 lzpanx.com · 只到门口

聚合夸克/百度/阿里网盘的搜索站，免登录，量极大：搜「斗破」夸克 14802 / 百度 1740 / 阿里 658，搜「斗破苍穹 合集」夸克 45323。

# 正确姿势：q 必须 urlencode，裸拼会 400
curl -s --data-urlencode "q=斗破" -G "https://www.lzpanx.com/search"

# 明细页 /doc/<id> 是 Astro SSR，直链在 /api/doc/<id> 但被签名挡住：
# {"code":401,"msg":"请求校验失败，请刷新页面后重试","details":{"reason":"invalid"}}

示例明细页：/doc/cltvkicoz004lx3bqjq0wegk9（这一条实测是视频合集，不是文包）。

带 Referer / X-Requested-With 也过不去。结论：只能拿来做「有没有这个资源」的线索判断，不能直取。

第一版主旧 PC 站 d1bz.net · 已换皮

返回 2190 字节的 JS 跳转页，内含三条线：

LINE_POOL = ["https://line1.ltxs520.click/", "https://line2.ltxs520.click/", "https://line3.ltxs520.click/"]

line1 → epgxs.net（一品阁，普通小说），line2 → lanseshuba.org（蓝色书吧）。2026-11 复测：早期判断「无搜索框、普通书站」是错的——搜索表单由 common.js 的 document.write 动态插入，静态 HTML 里看不到；实际它是第一版主旧 PC 站的书库，H 同人数量远多于 m.diyibanzhu.space（搜「斗破苍穹」一次出 30+ 本，全是 H 向改编）。正文走 ?ajax=1 接口，需要用 bsc.py 抓。
