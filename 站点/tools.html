工具链

全部在 采集工具/ 下，PowerShell 7。没有第三方依赖，没有 python。 调用方式统一：pwsh -NoProfile -File 采集工具/脚本名.ps1 -参数。

脚本层作用关键参数

截图.ps1采集Edge 无头截图：CSS 画布/图片化正文/JS 渲染的页面走这条路。-FullPage 用超长视口抓整页-Url -Urls -FromFile -OutDir -FullPage -WaitMs -Proxy

py/selftest.py自检逐包验证 ftfy/opencc/cn2an/rapidfuzz/datasketch/trafilatura/RapidOCR 可用性无

常用组合

正常扩库

pwsh -NoProfile -File 采集工具/搜集.ps1 -Queries "萧薰儿 调教","美杜莎 凌辱" -PerQuery 3
pwsh -NoProfile -File 采集工具/入库.ps1
pwsh -NoProfile -File 采集工具/校对.ps1
pwsh -NoProfile -File 采集工具/清理再生.ps1 -Apply     # 关键：把再生件移走
pwsh -NoProfile -File 采集工具/重建清单.ps1
pwsh -NoProfile -File 采集工具/校验.ps1
pwsh -NoProfile -File 采集工具/索引.ps1

打开一个加密压缩包

"/c/Program Files/WinRAR/WinRAR.exe" x -o+ -ibck -p"解压密码" \
  "F:\新建文件夹\read - 副本\原文\xxx.zip" \
  "F:\新建文件夹\read - 副本\_临时\zd\\"

目标目录必须是纯 ASCII 绝对路径，输出目录不能带中文也行——但源 zip 路径要加引号。

网页爬不到字 → 截图 + OCR

# 一条命令走完：截图 → OCR → 入库 → 校对 → 清理再生 → 清单 → 校验 → 索引 → 站点数据
pwsh -NoProfile -File 采集工具/流水线.ps1 -Mode full \
  -Urls "https://站点/章节页1.html|https://站点/章节页2.html" \
  -Title "章节全书名" -FullPage

# 也可以拆开跑
pwsh -NoProfile -File 采集工具/截图.ps1 -Url "https://..." -OutDir "_临时/shot/某书" -FullPage
powershell -NoProfile -ExecutionPolicy Bypass -File 采集工具/OCR.ps1 \
  -Path "_临时/shot/某书" -Merge -OutFile "采集工具/raw/某书.txt"

截图走 Edge 无头模式，不需要浏览器窗口；OCR 走 WinRT，只能用 powershell.exe 5.1（pwsh 7 加载不了 Windows.Media.Ocr）。
