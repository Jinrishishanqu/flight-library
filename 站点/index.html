这个站在记什么

① 资源站（sources）

每个站的可用性、门槛、抓取方式、实测命中量。分三档：免登录可爬 / 要账号 / 已失效。

  • pixiv：主力源，API 直取，命中率 80–90%
  • 第一版主移动版：免登录爬正文，斗破 20 本 / 斗罗 15 本
  • 老王论坛：Discuz + 软妹币 + clicaptcha，已实购 93 文件包
  • 萌の领域 / 维咔 / 尚香书苑：要登录或答题

② 采集管线（pipeline）

从「搜什么词」到「文件长什么样」的完整规则，含每步的判定标准。

  • 搜索策略：角色名/作品名 + H 词，比「同人」关键词高 4 倍命中
  • 入库：MD5 + 标题归一 + 前 200 字指纹，三层判重
  • 校对：固定行宽接回、标点错断接回、CRLF+UTF8BOM、章号合并
  • 校验：BOM / 裸 LF / 字符序列 / 字数目检，489/489 通过

③ 工具链（tools）

26 个 PowerShell 脚本的分工与调用方式。

  • 采集层：搜集 / 抽正文 / 清理再生
  • 整理层：入库 / 校对 / 合并 / 章拼接 / 重叠合并
  • 质检层：查重 / 查同书 / 男同筛查 / 校验 / 索引

④ 踩坑（lessons）

真正花掉时间的那些坑，一条都不删。

  • PowerShell 变量名大小写不敏感 → $a 覆盖 $A
  • "$chars字" 被当成变量 $chars字
  • 校对脚本不是增量，重跑会回滚人工合并成果
  • WinRAR AES 包 unzip 解不了，必须用 WinRAR.exe
