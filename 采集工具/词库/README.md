# 词库 / 校勘知识库

本项目所有「某个词该写成什么」的判断依据都集中在这个目录。校勘脚本、数据库构建、网站后端共用这份真相源，**不要在各处再散落词表**。

## 文件一览

| 文件 | 作用 | 格式 |
|---|---|---|
| `guard.txt` | 专名正写「白名单」，出现即保护、不参与纠错 | 每行一个词 |
| `confusion.txt` | 异写 → 正写，带作用域 | `错写<TAB>正写<TAB>作用域<TAB>备注` |
| `sex_terms.txt` | 情色/身体词汇规范表，兼断词白名单 | `词<TAB>类别<TAB>说明` |
| `typos.txt` | 错别字/错误表述 → 正确写法 | `错写<TAB>正写<TAB>全库命中数<TAB>类型` |
| `char_variants.txt` | 异体字/日文汉字 → 规范字 | `旧字<TAB>新字` |
| `watermark.txt` | 盗版站水印特征词 | 每行一个词 |
| `variants.json` | 打码/变形正则清单（机器可读） | JSON |
| `symbols.json` | 符号体例规范（引号/破折号/省略号…） | JSON |
| `lib.py` | 统一加载器 | Python |
| `原作信息.tsv` | **原作角色权威表**：性别、别名、身份 | `原作<TAB>角色<TAB>性别<TAB>别名<TAB>身份<TAB>备注` |
| `genders.txt` | 早期性别人工表（`原作信息.tsv` 的补充，已降级为兼容） | `名字<TAB>性别<TAB>备注` |
| `confusables.txt` | UTS #39 同形字映射（6,712 条，体检用，不参与替换） | Unicode 官方格式 |

## 为什么按这个结构分

校勘有四类判断，混在一起必然互相打架：

1. **保护**（`guard.txt`）—— 先执行。专名一旦被当成错字改掉，全库污染且难回滚。
2. **替换**（`confusion.txt`）—— 异写→正写。必须有作用域，否则跨作品串味（`妖妖` 全库 303 > `夭夭` 215，但在元尊域内 `妖妖=0`：全库统计会把别书人名当元尊错字）。
3. **还原**（`sex_terms.txt` + `variants.json`）—— 打码/自审变形还原为真用法。
4. **提示**（`typos.txt`）—— 只报不改或人工确认，成语误写有语境依赖。

**执行顺序是硬要求**：`打码还原 → guard 保护 → confusion 替换 → 断词还原 → 符号统一 → 台账`。顺序错了会出现「先替换后保护」把专名改坏的情况。

## 频次只能发现候选，裁定权在外部权威

全库实测的关键教训（写在这里免得以后重犯）：

| 现象 | 数据 | 结论 |
|---|---|---|
| 频次接近对半 | `紫研 2525 : 紫妍 2355` | 频次投票无意义，必须用户/原作裁定 |
| 作用域污染 | 全库 `妖妖 303 > 夭夭 215`，元尊域内 `妖妖=0` | 统计必须按作品切 |
| 单篇混用 | `《斗破苍穹之始于云岚》` 内 `薰儿=2 熏儿=1 紫研=0 紫妍=5` | 需要 per-file 一致性检查，不能只看全库 |
| 统计法失效 | 连写≥30 且断开≤6 的判据，候选 111 条全是误报（`萧玉，手上`、`痛快，感情`） | 断词只能「词表 + 上下文逐条核对」 |

## 怎么扩充

**加一个专名**：写进 `guard.txt`。同时若发现异写，在 `confusion.txt` 加一行，作用域写 `global`（全书通用）或作品目录名（只在该作品内替换）。

**加一个情色词**：写进 `sex_terms.txt`，给类别。加了之后它自动进入：断词还原白名单、词频统计、标签抽取、错别字检查的对照集。

**加一条错别字**：写进 `typos.txt`，第三列填全库命中数（跑一遍统计再填）。成语误写要谨慎，有的写法在特定语境是故意的。

**加一种打码手法**：写进 `variants.json` 的 `masks` 数组，写清 `pattern` / `replace` / `note`。如果 `replace` 为 null，说明需要词表配合（回调处理）。

**改符号体例**：只改 `symbols.json`。例如引号从 `「」` 改成 `“”`，改 `quote.primary` 与 `quote.nested` 两行，校勘脚本自动跟随。

## 已知限制

- `sex_terms.txt` 是**规范性**词表，不是全量词表。库里还有大量同义表达（`花径`、`玉茎`、`桃源`）未收录，按需补。
- `typos.txt` 只有 9 条，来自全库实际命中 ≥1 的成语/同音误写。通用错别字表（如「的地得」）**故意不收**——误伤率远高于收益，交给 pycorrector 抽样复核。
- `confusion.txt` 的 6 条防御性词对（`肖炎→萧炎` 等）当前全库 0 命中，保留是为了未来新增文本时自动生效。
- 打码还原依赖上下文枚举。拼音类（`Rou`→肉）已 100% 确认；中文标点类必须白名单，因为 `内，射` 既可能是打码也可能是 `体内，射在外面`。

- `采集工具\书库\build_characters.py` —— 读 `原作信息.tsv`（性别/别名）+ hanlp NER 出候选
