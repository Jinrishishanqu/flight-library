# 采集工具

项目根目录结构：

```
项目根\
├─ 原文\                按原作归档，未改动的原始文本
├─ 校对后文章\           排版层：按 文档\校对规则.md 处理，一个字不改
├─ 校勘版\              成品层：水印净化 + 打码还原 + 专名统一 + 标点体例 + 语汇还原
├─ 采集工具\            本目录（脚本 + 词库 + 记录 + 校勘流水线）
├─ 文档\                规则、报告、索引（书目索引.csv 在 文档\ 下）
├─ 站点\                本地静态记录站
├─ 归档\                备份 / 重复件 / 旧成品 / 参考源码
└─ README.md           项目导航
```

本目录内部：

```
采集工具\
├─ run-all.ps1        一条命令跑完四段
├─ sources.psd1       源定义（pixiv / qbtr）+ H 词表 + 自动检索靶子 + IP 归类规则
├─ 搜集.ps1           ① 抓取（多词检索 / 自动组合 / H 度判定）
├─ 入库.ps1           ② 判重 + 归类，不改一个字
├─ 校对.ps1           ③ 按 `文档\校对规则.md` 排版
├─ 校验.ps1           ④ 独立复核
├─ raw\<IP>\          ① 落盘处（入库后自动清空）
├─ 记录\              采集记录.csv / 入库清单.csv / 校对清单.csv / 校验报告.csv
├─ 校勘\              校勘流水线（S2 净化 + S3 体例）+ lex\ 词表
├─ py\                校对引擎 v2（normalize / build / verify / dedupe …）
└─ _legacy\           旧脚本存档
```

数据流：

```
sources (pixiv / qbtr)
  → 采集工具\raw\<IP>\*.txt          原样，不清洗
  → 原文\<IP>\*.txt                  判重后归档，字节不变
  → 校对后文章\<IP>\《作品》-章节-字数.txt
```

## ① 搜集.ps1 —— 只认 H 文

### ★ 检索词怎么打

**不要用「同人」做关键词**——这个词把结果拽向剧情向衍生文。有效打法是「**作品名 / 角色名 + H 词**」：

```
美杜莎 调教      小医仙 中出      比比东 凌辱      古月娜 催眠
斗破 淫          斗罗 肉         萧薰儿 内射      王冬儿 堕落
```

实测：`Tags 斗破苍穹` 60 篇只留 13 篇（21%）；`美杜莎 调教` 前 5 条全 H。换个词，命中率两成跳到八九成。

| 模式 | 参数 | 说明 |
|---|---|---|
| 自动组合 | `-Auto` | `sources.psd1` 里 `targets × hQueries` 笛卡尔积批量扫 |
| 手打词 | `-Queries '美杜莎 调教','斗破 中出'` | `s_mode=s_tag` 多词模糊匹配 |
| 标签全匹配 | `-Tags 斗破苍穹` | `s_tag_full`，量大靠 H 判兜底 |

```powershell
# 全靶子 × 5 个 H 词，每个查询最多取 3 篇
pwsh -File 采集工具\搜集.ps1 -Source pixiv -Auto -HQueries 调教,中出,淫,凌辱,催眠 -PerQuery 3

# 只补指定角色
pwsh -File 采集工具\搜集.ps1 -Source pixiv -Auto -Targets 雅妃,朱竹清,比比东 -HQueries 调教,中出 -PerQuery 5

# 备源（男频后宫长文，需书号）
pwsh -File 采集工具\搜集.ps1 -Source qbtr -Ids 10209
```

**H 度判定**：① tag 命中 `中出/口交/凌辱/调教/强奸/内射/潮吹/淫/性奴/NTR/肉文/R-18…` 直接算 H（繁简通吃）；② 否则正文词表密度 ÷ 千字，低于 `-HMin`（默认 2）丢弃。
**去重**：作品 URL 为键，可反复增量跑。

## ② 入库.ps1 —— 只归档，不动内容

```powershell
pwsh -File 采集工具\入库.ps1 -DryRun     # 预演
pwsh -File 采集工具\入库.ps1             # 正式入库（默认清 raw）
pwsh -File 采集工具\入库.ps1 -KeepRaw    # 保留 raw
```

三层判重：MD5 → 标题归一化 → 正文前 200 字指纹。归类按 `ipRules` 计分（文件名权重 3、正文权重 1，取最高分）。**不改编码、不改标点、不删广告行**。

## ③ 校对.ps1 —— 严格照 `文档\校对规则.md`

```powershell
pwsh -File 采集工具\校对.ps1 -DryRun
pwsh -File 采集工具\校对.ps1            # 原文\ → 校对后文章\
pwsh -File 采集工具\校对.ps1 -Force     # 强制重跑已校对过的
```

| README 条款 | 实现 |
|---|---|
| 严格解码 UTF-8 / UTF-16(BOM) / GB18030 | UTF-8 严格模式失败才回落 GB18030，坏字节不替换 |
| DOCX 按正文顺序提取 | 走 `word/document.xml`，`</w:p>`→换行、`<w:br/>`→换行 |
| ① 接回固定行宽断行 | 正文行显示宽度直方图（全角 2、半角 1）取众数 `W`；上行宽 ≥ `W-2` 且下行无缩进 → 接回 |
| ① 句号折行 | 文件有缩进规律（缩进行 ≥15%）时，无缩进行一律视为续行 |
| ② 错断标点 | 下行以 `，。、；：！？」』）”’）…` 开头 → 接回；半角字母数字相邻接回补空格 |
| ③ 保留段落标记 | `第X章/序章/楔子/前言/后记/尾声/番外/Chapter N`、独立数字行、分隔线、独立省略号独立成段 |
| ④ 段间距 | 清行尾空白，段间一空行，CRLF + UTF-8 BOM |
| ⑤ 存疑边界 | 线索不足不接回，错字/缺文/乱码原样带过 |
| 章节合并 | 同作品同正篇/续篇、章号连续才拼；支持中文数字（第一百六十章）；交界留一空行 |
| 命名 | `《作品》-章节-字数.txt`；`17` / `1~4` / `21、22、24` / `全篇` / `3篇`；字数按非空白字符，≥1万用 `w` 保留一位小数 |
| 幂等 | 清单里的来源自动跳过（`-Force` 重跑） |

## ④ 校验.ps1 —— 不复用校对的自述

```powershell
pwsh -File 采集工具\校验.ps1
pwsh -File 采集工具\校验.ps1 -Fix    # 修正文件名里错的字数
```

逐篇核：UTF-8 BOM、有无裸 LF、来源是否齐全、忽略空白后字符序列是否一致（带首个差异位置）、文件名字数是否符合取整规则。报告落 `记录\校验报告.csv`。

## 一条命令

```powershell
pwsh -File 采集工具\run-all.ps1 -Tags 斗破苍穹,斗罗大陆 -Pages 2
pwsh -File 采集工具\run-all.ps1 -SkipCollect      # 只跑 入库→校对→校验
```
