批式检索命令（结果页 → 提取 doc 链接）：

```bash
UA="Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/126.0"
for q in "斗破 同人" "斗罗 同人" "斗破苍穹 h" "斗罗大陆 合集" "天蚕土豆 同人"; do
  echo "== $q"
  curl -skL -m 25 -A "$UA" --get --data-urlencode "q=$q" https://www.lzpanx.com/search \
    | grep -oE 'href="/doc/[a-z0-9]+"' | sort -u | head -20
done
```
